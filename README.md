## 📌 Project Overview

This project focuses on analyzing Netflix movie data using Python and various data analysis libraries. The goal is to extract meaningful insights from the dataset and answer important business questions through Exploratory Data Analysis (EDA) and data visualization techniques.

The project demonstrates practical applications of data cleaning, data transformation, visualization, and analytical thinking using real-world entertainment industry data.

---

## 🎯 Problem Statement

Netflix is one of the world's leading streaming platforms, serving millions of users globally. By analyzing movie-related data, we can identify trends and patterns that help understand audience preferences and content performance.

This project answers the following questions:

- What is the most frequent genre of movies released on Netflix?
- Which movie has the highest vote average?
- Which movie has the highest popularity and what is its genre?
- Which movie has the lowest popularity and what is its genre?
- Which year has the highest number of movie releases?


